# Changelog

## v0.10 baseline

Initial GitHub baseline imported from the supplied `PSH_Automation_v0.10(2).gs`.

Key current behavior includes:

- IEM reconciliation for airport wind/gust/MSLP
- direct WeatherSTEM station-specific historical minute retrieval
- maximum valid WeatherSTEM minute Anemometer observation for sustained wind
- native WeatherSTEM 10-minute gust retrieval
- conservative WeatherFlow/manual handling
- CoCoRaHS resolver and report-station verification
- NOAA CO-OPS and conservative USGS NAVD88 handling
- Francine regression suite and coverage logging

No meteorological logic was intentionally changed during repository initialization.
